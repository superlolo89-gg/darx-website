# DARX website V2

Static responsive marketing website based on the DARX Hub71 investor pitch draft and updated business-health SWOT.

## Publish on GitHub Pages
Upload `index.html`, `styles.css`, and `script.js` to the root of your website repository. Under **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`. If the repository already has a deployment workflow, use that instead and verify its publishing directory.

## Squarespace
This is standalone HTML/CSS/JS, not a Squarespace template. To reproduce it on Squarespace, rebuild sections using native blocks or use supported code injection with appropriate plan permissions. The easiest full-code deployment is GitHub Pages.

## Before launch
- Replace `hello@darx.ai` in `script.js` with a verified working contact email. It is a placeholder, not a confirmed DARX address.
- Replace Google Fonts with approved DARX brand fonts if licensing permits.
- Add privacy notice, business details and legal pages.
- The dashboard is explicitly fictional. No live AI, scoring engine or review aggregation is implemented.
- Connect a real form backend before claiming to collect or store leads.
- Verify data access rights and claims before marketing product features as live.
- The pitch is a draft: do not present funding, customers, pilots or metrics as established without evidence.

## Content rationale
Preserves the deck's FIND / IMPROVE / BENCHMARK structure, five-layer engine, four business units, Abu Dhabi origin and evaluation-only positioning. Highlights business pain points, transparent scoring and advisor support from the SWOT and recent product clarification.
